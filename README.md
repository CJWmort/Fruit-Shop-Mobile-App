# Cross Platform Mobile App Development (CPMAD)

Year 3, Semester 1 end semester CPMAD module project

## About

A mobile app for the Yayapapaya.com website with the goal of "generating" more salees for the yayapapaya fruit shop.
App created using Flutter Software with the Dart programming language.
An upgraded version of the MAD project from Year 2, Sem 2. Now with database connection.
Connected to Firebase cloud database, mainly focused on creating the UI + working buttons + database query (search fields etc).

The app is used to order fruits online from the yayapapaya fruit shop, a Shopping Cart Application.
